# BrandSentimentClassifier — Multi-dimensional Sentiment Alert System

## Overview
Classifies brand social comments into 5 risk categories (quality_complaint, logistics_complaint, competitor_comparison, price_sensitive, other) and generates a prioritized alert briefing with shift detection. The pipeline uses an LLM for zero-shot classification, a calibrated abstention threshold, and deterministic rules for change-point alerts.

## Results
Two foundation models were benchmarked via OpenRouter. DeepSeek-V3.2 was selected as the primary model due to higher synthetic accuracy and better-calibrated abstention.
| Model | Dataset | N | Accuracy | Abstention | Keyword Baseline |
| :--- | :--- | :--- | :--- | :--- | :--- |
| DeepSeek-V3.2 | Synthetic | 200 | 94.92% | 1.5% | 76.0% |
| DeepSeek-V3.2 | Real held-out | 30 | 83.3% | 0.0% | 66.7% |
| Qwen-2.5-72B-instruct | Synthetic | 200 | 89.5% | 0.0% | 76.0% |
| Qwen-2.5-72B-instruct | Real held-out | 30 | 83.3% | 0.0% | 66.7% |
- Threshold: 0.3 (calibrated on a 20-comment development slice, balancing abstention ≤15% and non-abstained accuracy).
- Error pattern: Both models fail on multi-dimensional comments (e.g., price + quality mixed) and neutral statements that mention quality keywords without complaining.

## Files

- `output/eval_results.csv` — evaluation metrics
- `output/real_eval_results.csv` — real held-out evaluation metrics

- `output/real_eval_predictions.csv` — real set predictions with confidence

## How to run
1. Upload data/synthetic_reviews.csv and data/real_eval.csv to Google Drive under MyDrive/zara/
2. Open the notebook in Colab
3. Set `OPENROUTER_API_KEY` in Colab Secrets
4. Run all cells in order. The notebook defaults to DeepSeek-V3.2 (deepseek/deepseek-chat). To switch to Qwen, change the model parameter to qwen/qwen-2.5-72b-instruct
5. Outputs are written to /content/ and can be downloaded or synced to Drive.

## Limitations
- Threshold (0.3) is calibrated on a small development slice; larger-scale calibration may improve abstention behaviour.
- Real held-out set has only 30 comments; accuracy differences between models are not statistically significant.
- Main confusion: price_sensitive ↔ quality_complaint and competitor_comparison ↔ logistics_complaint when comments mix dimensions.
- The system is designed for human-in-the-loop review; it does not make automated crisis decisions.
- Synthetic data is generated by an LLM and may not fully represent real social media language distribution.
