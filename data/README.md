# Data Documentation

## synthetic_reviews.csv
- Source: Generated by DeepSeek-V3.2 via `generate_data.py`
- Size: 200 comments (40 per category)
- Columns: comment_id, comment_text, platform, true_category, batch_id
- Ground truth: Fixed at generation time; labels stripped before classification

## real_eval.csv
- Source: 30 public comments manually collected from Xiaohongshu/Douyin/Instagram
- Labels: Hand-labeled by me into 5 categories
- Privacy: Usernames, avatars, timestamps removed
- Held-out: Not used for prompt tuning or threshold calibration
